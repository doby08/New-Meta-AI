KUNG NAG-ERROR ANG "npm install" O "npm start" SA TERMINAL:
----------------------------------------------------------
Karaniwang dahilan at solusyon:

A) "npm is not recognized" o "node is not recognized"
   -> Walang Node.js. Solusyon:
   1. Pumunta sa https://nodejs.org
   2. Pindutin ang LTS (berdeng button), i-install.
   3. I-RESTART ang PC (o isara/buksan ulit ang VS Code).
   4. I-double click ulit ang SIMULAN-DITO.bat

B) "enoent Could not read package.json" o "no such file"
   -> Maling folder ang terminal. Solusyon:
   1. Sa VS Code: File > Open Folder > piliin ang "METa AI" folder mismo
      (dapat kita agad ang server.js at package.json).
   2. O sa terminal, gamitan ng QUOTES dahil may space ang path:
        cd "C:\Users\Ivy Banua\OneDrive\Desktop\kuya poy\METa AI"
      Pagkatapos:
        npm install
        npm start

C) "npm.ps1 cannot be loaded / running scripts is disabled"
   -> PowerShell ang problema. Solusyon:
   1. Huwag gumamit ng PowerShell. Gamitin ang Command Prompt:
      Sa VS Code terminal, pindutin ang + dropdown > Command Prompt.
   2. O mas madali: i-double click ang SIMULAN-DITO.bat (hindi na kailangan ng VS Code terminal).

D) "EAI_AGAIN / network / registry" o mabagal na install
   -> Walang internet o mahina. Solusyon:
   1. Ikonek sa internet, patayin muna ang VPN kung meron.
   2. I-double click ang AYUSIN.bat (kusa nitong lilinisin at i-install ulit).

E) "Port 3000 already in use"
   -> May lumang server na bukas. Solusyon:
   1. Isara ang lahat ng black window na may "node server.js".
   2. O i-restart ang PC, pagkatapos SIMULAN-DITO.bat ulit.

F) Nasa OneDrive ang folder (kagaya ng sa iyo)
   -> Minsan naka-lock ng OneDrive sync. Solusyon:
   1. Hintaying matapos mag-sync ang OneDrive (berdeng check).
   2. Kung ayaw pa rin: kopyahin ang buong "METa AI" folder sa
      C:\METa-AI  (walang space, walang OneDrive), at doon paandarin.

KUNG GUSTO MONG I-SCREENSHOT ANG ERROR:
----------------------------------------
1. Sa terminal, i-copy ang PULANG mensahe.
2. Isend mo dito para masabi ko ang eksaktong ayos.
3. O i-double click ang CHECK.bat at isend ang lumabas.
